# Καλάθι — τιμές σούπερ μάρκετ

Κάθε πρωί ένα GitHub Action επισκέπτεται τις δημόσιες σελίδες **660 προϊόντων**
σε **My Market και Μασούτη** (και 20 βασικών προϊόντων και στον **ΑΒ Βασιλόπουλο**),
κρατά τις τιμές και ενημερώνει ένα dashboard (GitHub Pages). Η συλλογή κρατά περίπου μία ώρα.

Τα προϊόντα αντιστοιχίστηκαν αυτόματα ανάμεσα στις αλυσίδες (ίδια μάρκα και ίδια
συσκευασία). Όπου η μία τιμή είναι πάνω από 2,5 φορές η άλλη, το dashboard το σημειώνει με ⚠ και δεν
το μετράει στα σύνολα, γιατί μάλλον δεν είναι ακριβώς το ίδιο προϊόν.

## Τι υπάρχει εδώ

| Αρχείο | Τι κάνει |
|---|---|
| `basket.yaml` | Η λίστα προϊόντων και τα links τους ανά αλυσίδα. **Μόνο αυτό χρειάζεται να αλλάζεις.** |
| `collector/collect.py` | Μαζεύει τις τιμές (καμία ανάγκη να το πειράξεις). |
| `docs/index.html` | Το dashboard. |
| `docs/data/` | Το ιστορικό τιμών και τα ονόματα όπως τα γράφει κάθε e-shop (ενημερώνονται αυτόματα). |
| `.github/workflows/daily.yml` | Το καθημερινό πρόγραμμα. |

## Στήσιμο στο GitHub (μία φορά)

1. Φτιάξε ένα νέο repository (π.χ. `kalathi`) και ανέβασε όλα τα αρχεία.
2. **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main`, φάκελος `/docs`.
3. **Actions**: πάτα *Καθημερινή συλλογή τιμών → Run workflow* για μια πρώτη δοκιμή.
4. Το dashboard θα είναι στο `https://<το-username-σου>.github.io/kalathi/`.

> Σε δημόσιο repository τα Actions είναι δωρεάν. Σε ιδιωτικό, ο δωρεάν λογαριασμός έχει
> 2.000 λεπτά/μήνα και η συλλογή χρειάζεται ~5 λεπτά/μέρα, άρα χωράει άνετα.
> Το GitHub Pages σε ιδιωτικό repository απαιτεί πληρωμένο πλάνο.

## Προσθήκη / αλλαγή προϊόντος

Αντέγραψε ένα μπλοκ στο `basket.yaml` και βάλε τα links της σελίδας του προϊόντος
από κάθε e-shop. Αν μια αλυσίδα δεν το έχει, γράψε `null`. Για έλεγχο ενός link:

```
python collector/collect.py --probe <link>
```

## Τοπική εκτέλεση

```
pip install -r requirements.txt
python -m playwright install chromium
python collector/collect.py
python -m http.server -d docs 8000   # και άνοιξε http://localhost:8000
```

## Περιορισμοί

- Οι τιμές είναι **τιμές e-shop, πανελλαδικές** (δεν διαφέρουν ανά περιοχή).
- Σκλαβενίτης και PosoKanei μπλοκάρουν αυτοματοποιημένη πρόσβαση, οπότε δεν περιλαμβάνονται.
- Ο ΑΒ περιορίζει την αυτοματοποιημένη πρόσβαση, γι' αυτό παρακολουθείται μόνο για τα 20 βασικά προϊόντα.
- Όταν αλλάζει το `basket.yaml`, η συλλογή ξεκινά αυτόματα.
- Αν κάποιο e-shop αλλάξει τη σελίδα του, οι τιμές του θα εμφανιστούν στο κουτί
  «Τιμές που δεν συλλέχθηκαν» μέχρι να διορθωθεί ο collector.
- Μία επίσκεψη ανά προϊόν τη μέρα, με καθυστέρηση 2–4 δευτερολέπτων ανάμεσα σε αιτήματα προς την ίδια αλυσίδα.
